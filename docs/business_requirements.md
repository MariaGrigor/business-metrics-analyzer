# Бизнес-требования

## 1. Назначение системы

Система предназначена для расчёта и визуализации ключевых показателей эффективности (KPI) предприятия розничной торговли.

Система должна помогать анализировать показатели предприятия по месяцам, выявлять убыточные периоды и принимать решения по оптимизации расходов.

## 2. Бизнес-задача

Предприятие розничной торговли хочет анализировать ежемесячные показатели деятельности.

Основные показатели:

- выручка;
- затраты;
- рентабельность;
- средний чек.

Цель анализа — выявление убыточных месяцев и оптимизация расходов предприятия.

## 3. Функциональные требования

Система должна:

1. Хранить данные о показателях предприятия по месяцам.
2. Рассчитывать среднюю выручку за выбранный период.
3. Рассчитывать показатель рентабельности.
4. Выводить результаты расчётов в консоль.
5. Подготавливать данные для последующей визуализации KPI.
6. Позволять анализировать показатели предприятия по месяцам.

## 4. Расчёт рентабельности

Рентабельность рассчитывается по формуле:

Рентабельность = (Выручка - Затраты) / Выручка × 100%

Если выручка равна нулю, результат расчёта должен быть равен 0.

## 5. Планируемые KPI

В дальнейшем планируется анализировать следующие показатели:

- ROI (возврат инвестиций);
- оборачиваемость товаров;
- конверсия;
- выручка;
- затраты;
- рентабельность;
- средний чек.

## 6. Результат работы системы

Результатом работы системы должны быть рассчитанные значения KPI, которые позволяют оценить эффективность деятельности предприятия и выявить проблемные периоды.

## 7. Технологический стек

Для реализации проекта используются:

- Python 3.10+;
- pandas;
- matplotlib.
